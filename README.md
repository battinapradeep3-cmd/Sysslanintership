🎉 Party Vibes – Event Ticket Booking System

📌 Project Overview
https://battinapradeep3-cmd.github.io/Sysslanintership/
Party Vibes is a front-end event ticket booking website designed for users to discover and book tickets for exciting events such as DJ nights, live concerts, and music festivals.

The website is developed using HTML, CSS, and JavaScript. It provides an attractive, responsive, and interactive user interface for browsing events, selecting tickets, and completing a demo booking process.

This project is developed as part of the Front-End Development Internship at Sysslan IT Solutions.

---

🎯 Project Objectives

The main objectives of this project are:

- Create a structured and user-friendly event booking website.
- Design an attractive Party Vibes interface.
- Display multiple entertainment events.
- Allow users to view event details.
- Provide different ticket categories and prices.
- Add interactive booking functionality.
- Validate mobile numbers, OTP, and booking forms.
- Make the website responsive for mobile, tablet, and desktop devices.

✨ Features

🏠 Home Page

The home page contains:

- Party Vibes logo
- DJ/music event image
- Welcome message
- Mobile number input
- Demo OTP verification
- Scroll-down navigation

🎉 Events

Users can browse different events such as:

- 🎧 DJ Night
- 🎤 Live Concert
- 🎵 Music Festival

Each event contains:

- Event image
- Event name
- Date
- Location
- View Event button

🎟️ Ticket Booking

Users can select different ticket categories:

- Normal Ticket – ₹500
- VIP Ticket – ₹1,000
- Premium Ticket – ₹1,500

Users can also select the number of tickets.

The total price is calculated using:

Total Price = Ticket Price × Number of Tickets

📝 Booking Form

The booking form contains:

- Full Name
- Email
- Event Selection
- Number of Tickets
- Confirm Booking button

JavaScript checks the required information before confirming the booking.

🔐 Login

The website provides a login section with:

- Mobile Number
- OTP/Password
- Login button
- Sign-up option

📱 Responsive Design

The website is designed to work on:

- Mobile phones
- Tablets
- Desktop computers

🚀 How to Run the Project

Step 1

Download or clone the project.

Step 2

Open the project folder.

Step 3

Make sure the following files are present:

index.html
style.css
script.js

and the "images" folder contains the required images.

Step 4

Open:

index.html

in a web browser.

Step 5

Explore the website:

1. Enter mobile number.
2. Verify the demo OTP.
3. Scroll to upcoming events.
4. Select an event.
5. View event details.
6. Select a ticket.
7. Enter booking details.
8. Confirm the booking.
9. Test the login section.
